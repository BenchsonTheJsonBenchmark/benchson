## Validation seed selection
Validation selection is deterministic: seeds are searched in order starting at 0 and the first seed that yields exactly 100
validation rows per task is used. Seed 0 was selected (127 schema contents). Recorded in `manifests/split_summary.json`.

## Reproducing: local directories required
The preparation scripts read local copies of the baseline (`data_published/7962b0947f7d/original_files/`) and release
(`release/scale-only-7k/`, including `row_origin.tsv`) directories; both must be present at those paths when reproducing the
experiment. The scripts do not download anything. Tests report "NOT VERIFIED" (skipped) when these or the generated split are missing.
